Windows · 临时引流到 VPN

这是什么？

VPN 已连接但 SSH 不通时，worker 流量可能仍走普通网络。这里读取本机连接与路由，生成只针对所选 worker IP 的临时路由，不影响所有网站，也不会自动执行或申请管理员权限。

请先连接公司 VPN，再检测。网卡名称只能提供线索，请核对所选 VPN 网卡和网关；多个候选时需手动选择。端点可能来自旧错误或 ssctl 网络连接，不一定仍是当前 worker。

  2. 右键 Windows 开始菜单，打开“终端（管理员）”或“Windows PowerShell（管理员）”。

VPN 重连或 worker 改变后需重新检测。路由正确也不保证 VPN 允许访问服务器。刷新状态检测失败可能重建隧道。
