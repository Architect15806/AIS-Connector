使用最新 SSH 指令连接服务器

连接原理

插件负责登录认证、建立隧道和定时检测，并将可用连接同步到本机 JSON 文件。文件的键是连接别名，值是当前 SSH 命令。隧道重建后端口可能变化，所以 Agent 每次建立新连接前都应重新读取文件。

Agent 必须与插件运行在同一台电脑；127.0.0.1 指向本机。连接失效或重连中时，文件中可能暂时没有该别名。更新文件不会自动恢复已中断的 SSH 会话。

1. 在插件中准备连接

添加用户并登录认证，初始化目标连接，等待“SSH 验证通过”。

2. 让 Agent 阅读项目内的 skill

将以下文件路径发给 Agent，并告诉它要连接的完整别名。也可以按照所用 Agent 工具的规则安装该 skill；此页面不会自动安装。

3. 每次读取最新命令

Agent 先读取 JSON，按别名选择连接，再用 SSH 执行只读检测。失败后重新读取并重试一次；仍失败则提醒你更新登录状态，不自行重建插件的隧道。
